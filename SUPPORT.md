## Before Filing an Issue

1. **Search existing issues** — Your question may already be answered.
2. **Check the documentation** — See the [docs directory](docs/) for architecture, API reference, and configuration guides.
3. **Try the latest version** — The issue may already be fixed.

## When Filing a Bug Report

Include as much of the following as possible:

- OpenSQS version
- Go version
- Operating system
- Steps to reproduce
- Expected vs. actual behavior
- Relevant logs (redact secrets)
- Configuration file (redact secrets)
